## Overview

This repository contains practical ML tasks focused on real-world workflows: understanding data, building baselines, training models, evaluating results, and communicating insights through notebooks.

---

## Projects

| Project | Main Idea |
|---|---|
| `Student Score Prediction` | Predict student performance using study and lifestyle factors |
| `Customer Segmentation` | Segment mall customers using unsupervised learning |
| `Movie Recommendation System` | Build recommendation logic using the MovieLens 100K dataset |
| `Traffic Sign Recognition` | Train a CNN model for traffic sign image classification |

---

## Skills Practiced

- Exploratory data analysis and visualization
- Feature preprocessing and model selection
- Regression and classification workflows
- K-Means customer segmentation
- Collaborative filtering recommendation concepts
- CNN training with PyTorch
- Model evaluation and project reporting

## Getting Started

Open any project folder and run its notebook:

```bash
jupyter notebook
```

Install the common ML stack if needed:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn torch torchvision
```

# 🚀 My Machine Learning Journey: 4 Diverse Projects

Excited to share my recent work on **4 machine learning projects** that showcase different aspects of data science and AI! Each project demonstrates unique techniques and real-world applications.

## 📊 Customer Segmentation Analysis
**Objective:** Segment mall customers to identify distinct customer groups for targeted marketing

**Key Highlights:**
- Used **K-Means clustering** on customer demographics and spending behavior
- Applied advanced clustering techniques for optimal group identification
- Created comprehensive visualizations and business insights
- Enables targeted marketing strategies and personalized customer experiences

**Tech Stack:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn

---

## 🎬 Movie Recommendation System
**Objective:** Build a collaborative filtering system to recommend movies to users

**Key Highlights:**
- Implemented **Collaborative Filtering** using the MovieLens dataset
- Built both **User-Based** and **Item-Based** recommendation engines
- Used **Cosine Similarity** for finding similar users and movies
- Powers recommendation engines like Netflix and Amazon Prime

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, Scipy

---

- Generated actionable insights for educational improvement

## 🚦 Traffic Sign Recognition (Deep Learning)
